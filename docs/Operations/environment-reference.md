# Environment Variable Reference

Source of truth:

- `.env.example`
- `dashboard/.env.example`
- `src/config/env.ts` (validation + defaults)

## Minimum Requirements

### Local development (safe)

Required software:

- Node.js 20+
- npm

Recommended settings:

- `TRADING_MODE=paper` or `TRADING_ENABLED=false`
- `OPS_API_TOKEN` set in `.env` (required for `npm run dev:ops`)
- Runtime session login at `/ops/*` using `OPS_API_TOKEN`

### Live mode (required keys)

When `TRADING_ENABLED=true` and `TRADING_MODE=live`, these keys are required by runtime validation:

- `ALCHEMY_API_KEY`
- `POLYMARKET_API_KEY`
- `POLYMARKET_API_SECRET`
- `POLYMARKET_PASSPHRASE`
- `POLYMARKET_POSITIONS_USER`

## Priority Keys

### Priority 1 (must-have for live trading)

`ALCHEMY_API_KEY`, `POLYMARKET_API_KEY`, `POLYMARKET_API_SECRET`, `POLYMARKET_PASSPHRASE`, `POLYMARKET_POSITIONS_USER`

### Priority 2 (strongly recommended)

`OPS_API_TOKEN`, `TRADING_MODE`, `RISK_PROFILE`

### Other market integrations

- Active now: Polymarket
- Optional integration target: Kalshi (no runtime feature flag)
